# マルチチャネル通知システム 運用マニュアル

対象: 不動産管理会社 スタッフの皆様
最終更新: 2026年9月

## 普段の確認

- Slackの `#物件連絡` チャネルを見るだけでOKです
- メール・LINEに届いたお問い合わせは、AIが自動で「賃貸/売買/内見/クレーム」に
  分類し、このチャネルに転送されます
- **緊急対応が必要なクレーム**(設備故障・苦情など)は、Slackに加えて
  緊急連絡用LINEグループにも自動で通知されます

## 障害だと感じたら

以下のような場合は、開発担当まで連絡してください。

- 5分以上、メールやLINEへの問い合わせに対してSlack通知が来ない
- 明らかに関係のない内容が緊急通知として届く
- LINEグループへの通知が来ない(クレームのはずなのに)

## 緊急連絡用LINEグループについて

- クレーム(設備故障・苦情等)が来た場合、自動で「物件緊急通知」グループに
  通知されます
- メンバーの追加・削除は、通常のLINEグループ操作と同じ方法で行えます
- Botを誤ってグループから削除すると通知が届かなくなるため、ご注意ください

## よくある質問

**Q. 電話での問い合わせはこのシステムに含まれますか?**
A. 含まれません(今回のMVP範囲外)。Phase 2として別途ご提案しています。

**Q. 分類が間違っていることがあります**
A. AIによる自動分類のため、まれに誤分類が発生します。明らかにおかしい分類が
続く場合は開発担当にご連絡ください、分類ロジックを調整いたします。

**Q. 夜間・休日も通知は届きますか?**
A. はい、24時間365日、システムが自動で監視・通知しています。
